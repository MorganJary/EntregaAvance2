# EntregaAvance2
Entregables Analisis de Datos
Proyecto: Análisis de entornos alimentarios en la Región Metropolitana
Integrantes: Daniel Romero, Sebastián Bunzli, Benjamín Buzeta

Datos extraidos desde la investigacion nutricional entregado por la Investigadora Pinheiro, OpenStreetMap, GoogleMaps, Ministerio de Educación de Chile, Subsecretaría de Educación. (2024) y Ministerio de Desarrollo Social y Familia. (2024). SAE multidimensional e ingresos 2024. Gobierno de Chile.

El codigo puede ser ejecutado tras instalar los repositorios correspondientes, sin mas requerimientos.
